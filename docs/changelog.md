# Changelog

## 1.9.3

- 登录入口定位改为优先精确锚定游戏页真实结构 `#joinBtn`（`<button class="join" id="joinBtn">LinuxDO 登录</button>`），再回退到 OAuth 跳转链接与关键词匹配，比遍历更稳、更不易误命中。

## 1.9.2

- 修正"等冷却"的位置:此前等冷却发生在 connect.linux.do 授权页上长时间挂着(会因 OAuth 会话失效而点不动、还会命中旧 8/30 分钟超时停轮询)。改为离开后仍在游戏域名页(登出态)等冷却,授权页只负责"一到就点允许"快速通过。
- 新增游戏域名页登出态重连看护 `gameReconnectWatcher`(IIFE 顶层,纯 DOM+GM,不依赖游戏变量):读离开记录按类型算冷却、显示倒计时、冷却到期找 LinuxDo 登录入口点掉跳授权页。
- 防误触硬规则:只在"重连开关开 + 合法离开记录(damage/lowhp/stamina) + 页面出现了 LinuxDo 登录入口(=未登录态)"三条件同时满足时才行动;正常挂机时登录入口不在场,看护什么都不做,绝不自作主张戳登录。
- 授权页 `oauthReconnectMain` 简化为快速通过:立刻找"允许"并点掉、找不到 60 秒内重试、去掉原长冷却倒计时与无关超时。

## 1.9.1

- 授权页按钮匹配按 LINUX DO Connect 实际结构优先锚定 `a.btn-pill.btn-pill-primary`，再回退关键词命中，避免点错或漏点。
- 新增重连后低血安全恢复态：自动重连回游戏后先不自动巡航，进入 `REJOIN` 看护——若 170m（lowhp 重连放宽到 250m）内出现富敌/移动威胁，立即再离开，杜绝“几滴血出生在敌人旁边被秒”。
- 看护期内 HP 恢复过 40 且持续 8 秒无近身威胁后，自动解除恢复态并恢复挂机；用户手动点“启动”也会立即接管解除。
- HUD mode 显示 `REJOIN LOWHP/DAMAGE/STAMINA` 状态提示。

## 1.9.0

- 自动重连（PC）：掉血/体力离开后浏览器会跳到 `connect.linux.do` 授权页，现脚本在该域名下也注入轻量逻辑，自动点“允许”重回游戏，无人值守挂机不再中断。
- 冷却按离开类型区分：1h 体力耗尽离开等 60 分钟；掉血离开但离开时 HP ≤ 25 等 30 分钟；HP > 25 的掉血离开立即重连；手动点“离开”不自动重连。
- 新增 HUD “重连 ON/OFF” 开关（默认开），状态持久化在篡改猴 GM 存储、跨域共享；关闭后授权页不再自动点允许。
- 离开记录（类型/时间/HP）通过 GM 跨域存储在游戏域名写、授权页读，授权页未加载出“允许”按钮时静默等待、绝不乱点；带防重复 ack 与 8 分钟轮询上限。
- 头部新增 `@match https://connect.linux.do/*` 与 `@grant GM_setValue/GM_getValue/GM_deleteValue`。

## 1.8.2

- 逃离顺路收币：锚点金币到达 `COIN_REACHED_CM` 或超过 `FLEE_ANCHOR_MAX_MS` 后立刻排除当前点换下一颗安全锚点；没有下一颗则回纯反向撤离，修复“捡完一颗后原地转圈、敌人逼近无反应”。
- 金币路线评分：新增首段路程偏好 `ROUTE_NEAR_PREFER_CM` / `ROUTE_FAR_SOFT_CM`，第一颗金币过远时额外压分，减少偶尔突然冲很远处金币。
- 金币拾取：贴近停止半径从 45cm 提到 160cm（`COIN_REACHED_CM`），避免八向移动步长过大时在金币周边超调转圈吃不到。
- 手机端同步：沿轴时间估算 42cm/tick、首段路程偏好、金币贴近半径与 PC 对齐（mobile `@version` 0.1.2）。

## 1.8.1

- 常态金币巡航新增轻量弹道躲避：复用临时交战的弹道预测与八向躲避评分，但不进入交战模式、不清金币路线、不改 HP 离开逻辑。
- 当压迫度超过 `CRUISE_DODGE_PRESSURE` 或近弹进入 `CRUISE_DODGE_NEAR_CM` 时，短暂横移躲避；`CRUISE_DODGE_HOLD_MS` 结束后立刻恢复巡航。
- 追杀模式与临时交战模式下不启用巡航躲弹，避免和既有移动分支抢控制权。
- 脱战/停止脚本时清空 `cruiseDodgeUntil` 状态。

## 1.8.0

- 金币路线评分：八向移动时间估算沿轴系数从 50cm/tick 调到 42cm/tick（`TRAVEL_TICK_AXIS_DIV`），修正斜对角方向远金币秒收益被高估、压过近处金团的问题。同金额散落金币场景下，脚本不再首选远处斜向那颗。
- 金币路线评分：新增路线总长软折扣（`ROUTE_LENGTH_PENALTY_*`）。路线全程超过 300m 起点后按斜率压分、最多砍一半，让远处长路线相对变贵、近处金团路线自然胜出，减少"绕过近处去吃远处"。
- 危险规避：170m/220m 逃离改为两阶段撤离。刚触发仍纯反向拉开（避免路过的玩家引发一过性抖动）；同一敌人持续逼近超过 1.5 秒仍未摆脱，转去逃向一颗远离所有 170m 威胁敌人的安全金币锚点顺路收币，减少来回横跳空耗体力。无安全金币时退回纯反向，敌人离开 170m 后自动清状态回巡航。
- 新增 `safeFleeAnchor`，在撤离时选最近安全金币作为撤离目标。
- 撤离锚点状态 `runner.fleeAnchor` 在脱战、停止脚本、敌人离开危险距离时统一清空。
